# Mission PS5 – Kaufkalender Weihnachten 2026

Ein interaktiver iPhone-Kaufkalender für PS5-Konsolen, Spiele, Zubehör und Bundles in Deutschland.

## GitHub Pages einmalig einschalten

Öffne **Settings → Pages** in diesem Repository. Unter **Build and deployment** wähle:
- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** /(root)
- **Save**

Website anschließend: https://sabinemegow.github.io/ps5-kaufkalender/

**Wichtig:** Ein im Repository vorhandenes `index.html` allein veröffentlicht noch keine GitHub-Pages-Seite. Der Website-Link ist erst nach erfolgreicher Pages-Bereitstellung erreichbar.

## Inhalt und Datenschutz

193 anfängliche Produkte/Angebote, davon 190 eigenständige Einträge aus Veepee-Screenshots vom 08.11.2026 sowie weitere dokumentierte Preisbeobachtungen. Ein früherer Händlervergleichspreis ist kein unabhängig bestätigter Rabatt. Es gibt keine automatische Live-Preisüberwachung.

Favoriten, persönliche Notizen, eigene Preisänderungen und Preisverläufe werden nur lokal im jeweiligen Browser gespeichert. Sie werden **nicht** ins öffentliche GitHub-Repository geschrieben und **nicht** zwischen Geräten synchronisiert. Nutze regelmäßig den JSON-Export als Backup.

Öffne die veröffentlichte Webseite in Safari → Teilen → Zum Home-Bildschirm.
